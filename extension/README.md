# 拍卖采集助手（Chrome 插件）

在任意拍卖网页上一键加入拍卖价格采集平台。

## 安装
1. 打开 Chrome（或 Edge）的扩展管理页 `chrome://extensions`，打开右上角「开发者模式」
2. 点击「加载已解压的扩展程序」，选择本目录 `extension/`
3. 点击浏览器工具栏中的插件图标，填写平台地址（如 `http://服务器IP:8080`）并用操作员或管理员账号登录

## 使用
1. 打开拍卖平台的列表页 / 搜索结果页
2. 点击插件图标：
   - 已有内置模板的网站（如阿里资产、AllSurplus）会自动选择模板
   - 其他网站可选择「AI 自动生成规则」（需在平台中开启 AI）
   - 勾选「带上我在该网站的登录状态」会把当前浏览器中该网站的 Cookie 一并保存（加密存储），解决需要登录的网站
3. 点击「加入采集」，可选择立即采集一次

插件只与你填写的平台地址通信，登录令牌保存在插件本地存储中。
